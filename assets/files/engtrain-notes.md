## 第一章 工程材料基础

### 1.1 材料分类

工程材料分为两大类：

- **金属材料**
  - 黑色金属：钢、铸铁
  - 有色金属：铝、铜、镁、钛及其合金等
- **非金属材料**：高分子材料、陶瓷材料、复合材料等

### 1.2 材料性能

材料性能分为使用性能和工艺性能两大类：

| 性能类别 | 具体内容 |
|---------|---------|
| **使用性能** | 力学性能（强度、硬度、刚度、塑性、韧性等）、物理性能、化学性能 |
| **工艺性能** | 铸造性能、焊接性能、压力加工性能、切削性能、热处理性能 |

### 1.3 常用金属材料牌号

#### 碳素钢

| 牌号 | 含义 | 典型应用 |
|------|------|---------|
| **Q235A** | Q—屈服强度，235—屈服强度值 235 MPa，A—质量等级 | 螺栓、连杆、法兰等 |
| **45** | 数字表示钢中碳的平均质量分数的万分之几，即含碳量 0.45% | 轴承、齿轮、轴类等 |
| **T8 / T12** | T—碳素工具钢，数字表示碳的平均质量分数的千分之几（T12 即 1.2%） | 刀具、模具、锉刀、锯条等 |

#### 合金钢

- **12Mn**：首两位数字表示碳的质量分数的万分之几（0.12%），元素符号后数字表示该元素含量的百分之几，小于 1.5% 不标。
- 合金钢是在碳素钢基础上加入合金元素，使材料性能提高或具有特殊性能。

#### 铸铁

| 牌号 | 类型 |
|------|------|
| **HT200** | 灰铸铁（HT—灰铁，200—最低抗拉强度 MPa） |
| **KTH330-08** | 可锻铸铁（黑心可锻铸铁） |

### 1.4 热处理工艺

热处理是将工件加热到一定温度，经保温后以一定冷却速度冷却，使钢的组织和性能发生改变的工艺。

#### 四种基本热处理工艺

| 工艺 | 冷却方式 | 主要作用 |
|------|---------|---------|
| **退火** | 随炉冷却（炉冷） | 降低硬度、消除内应力、改善组织性能；包括完全退火、球化退火、去应力退火 |
| **正火** | 空气中冷却（空冷） | 细化晶粒、消除内应力；低碳钢正火可提高强度和硬度、改善切削加工性能 |
| **淬火** | 快速冷却（大于临界冷却速度） | 获得马氏体组织（硬、脆）；45 钢淬火后硬度可达 50～55 HRC，碳素工具钢大于 60 HRC |
| **回火** | 重新加热到临界点以下，保温后缓慢冷却 | 调整韧性、弹性、综合力学性能 |

#### 回火分类

随回火温度升高，钢的强度和硬度下降，塑性和韧性上升。

| 回火类型 | 温度范围 | 硬度 | 主要应用 |
|---------|---------|------|---------|
| **低温回火** | $150 \sim 250^\circ\text{C}$ | 58～64 HRC | 各种工、量、模具及滚动轴承（如 T12 钢锯条、锉刀） |
| **中温回火** | $350 \sim 500^\circ\text{C}$ | 35～45 HRC | 各种弹簧（获得较高弹性极限和强度） |
| **高温回火** | $500 \sim 650^\circ\text{C}$ | 25～35 HRC | 轴、齿轮、连杆等重要结构零件（综合力学性能好） |

#### 调质处理

**调质处理 = 淬火 + 高温回火（$500 \sim 650^\circ\text{C}$）**

经调质处理后的零件，既具有一定的强度、硬度，又具有一定的塑性和韧性，即综合力学性能较好。主要用于轴、齿轮、连杆等重要结构零件。

## 第二章 铸造

### 2.1 铸造概述

铸造是熔炼金属，制造铸型并将熔融金属浇入与零件形状相适应的铸型，凝固后获得一定形状和性能的铸件的成形方法。

#### 铸造特点

| 优点 | 缺点 |
|------|------|
| 适应性强，可制成形状和内腔十分复杂的铸件（特别是带内腔的毛坯，如箱体、气缸体、气缸盖等） | 铸件尺寸精度不高，表面粗糙，一般需经切削加工才能成为零件 |
| 可用于各种材料（有色、黑色金属、铸铁、铸钢等），以黑色金属为主 | 生产工艺过程难以精确控制 |
| 可生产不同尺寸及质量的铸件（壁厚可小于 1 mm，质量从几克到几百吨） | 化学成分和组织不均匀、晶粒粗大、组织疏松，常有气孔、夹渣、砂眼等缺陷 |
| 生产成本低，设备投资少，原材料价格低、来源广 | 力学性能不如锻件高 |

#### 铸造应用

主要应用在各种箱体和非承受载荷的低速齿轮等，如机床床身、齿轮箱、变速箱、手轮、内燃机气缸体、气缸盖、火车轮、皮带轮、台虎钳钳座等。

### 2.2 铸造主要工艺参数

1. **收缩余量**
2. **加工余量**
3. **起模斜度**：与壁高、造型方法、模样材料及表面粗糙度有关
4. **铸孔、槽及型芯头**
5. **铸造圆角**

### 2.3 砂型铸造工艺

#### 型砂组成

型砂 = 原砂 + 粘结剂（黏土/水玻璃/树脂）+ 附加物

#### 造型方法

- **手工造型**：整模两箱造型、分模两箱造型、挖砂造型和假箱造型、活块造型、刮板造型、三箱造型等
- **机器造型**

#### 造芯

- 型芯的主要作用是形成铸件的内腔
- 芯砂的性能要求比普通型砂的综合性能要高

### 2.4 分型面选择（最重要考点）

分型面是指上、下砂型的接触表面。

**分型面确定原则：**

1. 分型面应选择在模样的**最大截面处**，便于起模
2. 应使铸件上的**重要加工面朝下或处于垂直位置**
3. 应使铸件全部或大部分在**同一砂箱内**，以减少错箱和提高精度（一般重要加工面放在下箱）
4. 尽量减少砂芯数量
5. 分型面尽量为平面，避免曲折分型面

### 2.5 浇注系统

浇注系统是指液体金属流入铸型的通道，能平稳地将液体金属引入铸型，有利于挡渣和排气，并能控制铸件的凝固顺序。

如浇注系统开设得不好，铸件易产生浇不足、缩孔、冷隔、裂纹和夹杂物等缺陷。

#### 浇注系统组成

$$\text{浇口杯（外浇口）} \rightarrow \text{直浇道} \rightarrow \text{横浇道} \rightarrow \text{内浇道}$$

| 组元 | 功能 |
|------|------|
| **外浇口（浇口杯）** | 缓冲液体金属浇入时的冲击力，分离熔渣（挡渣） |
| **直浇道** | 连接外浇口和横浇道的垂直通道，利用其高度使金属液产生一定的静压力而迅速充满型腔 |
| **横浇道** | 连接直浇道和内浇道，位于内浇道之上；稳定金属液流动，使其平稳经内浇道流入型腔及向各内浇道分配金属液，并起**挡渣作用**（主要挡渣区域，需保证充满） |
| **内浇道** | 直接和型腔相连的通道，可控制金属液流入型腔的位置、速度和方向 |

#### 浇注系统类型

| 类型 | 截面积关系 | 特点 | 适用 |
|------|-----------|------|------|
| **封闭式** | $F_{\text{直}} > F_{\text{横}} > F_{\text{内}}$ | 挡渣好 | 灰铸铁常用 |
| **开放式** | $F_{\text{直}} < F_{\text{横}} < F_{\text{内}}$ | 充型平稳 | 有色金属常用 |

### 2.6 冒口与冷铁

- **冒口**：主要起**补缩作用**，同时兼有排气、浮渣及观察金属液体流动情况等功能。一般安放在铸件**热节（最厚大处）上方**。
  - 顺序凝固原则：远离冒口处先凝固，冒口最后凝固。
- **冷铁**：加速局部冷却，细化晶粒。

### 2.7 熔炼设备

| 合金类型 | 熔炼设备 |
|---------|---------|
| 铸铁 | 冲天炉 |
| 铸钢 | 电弧炉 |
| 有色金属 | 坩埚炉 |

### 2.8 浇注温度

- **浇注温度偏低**：金属液流动性差，易产生浇不足、冷隔、气孔等缺陷
- **浇注温度过高**：铸件收缩大，易产生缩孔、裂纹、晶粒粗大及粘砂等缺陷

合适的浇注温度应根据铸造合金种类、铸件的大小及形状等确定。

### 2.9 特种铸造对比

| 方法 | 原理 | 精度 | 适用场景 | 关键限制 |
|------|------|------|---------|---------|
| **金属型铸造** | 金属铸型反复使用 | 较高 | 大批量有色件（铝/镁/铜合金） | 无透气性/退让性，须尽早开型 |
| **熔模铸造** | 蜡模 + 陶瓷壳，脱蜡后浇注 | 极高（CT4～7） | 涡轮叶片等复杂小件 | 工序繁杂，成本高，铸件 < 25 kg |
| **压力铸造** | 高压高速压入金属型 | 极高 | 大批量薄壁有色小件 | 内部气孔多，不能热处理（加热膨胀起泡） |
| **离心铸造** | 旋转中浇注，离心力充型 | 较高 | 空心旋转体（管/套） | 内孔自由表面粗糙 |
| **低压铸造** | 低压气体压液上升充型 | 较高 | 汽车轮毂、缸体 | — |

#### 离心铸造特点

在离心力作用下充型，组织致密，无缩孔、气孔、渣眼等缺陷，力学性能较好。铸造空心旋转体铸件不需要型芯和浇注系统，铸件不需要冒口补缩，省工省料、生产率高、质量好、成本低。

### 2.10 常见合金铸造性能

| 合金 | 铸造性能特点 |
|------|-------------|
| **灰铸铁** | 接近共晶成分，流动性最好，收缩小 — **铸造性能最佳** |
| **铸钢** | 熔点高，流动性差，收缩大，必须设大量冒口 |
| **铝合金** | 易吸气（针孔），需除气精炼 |

### 2.11 铸造应力

厚壁受**拉应力**，薄壁受**压应力**。

## 第三章 压力加工

### 3.1 压力加工概述

压力加工是指对坯料施加外力，使其产生塑性变形，改变形状、尺寸和改善性能，以制造零件或毛坯的成形加工方法。**锻造和冲压总称锻压。**

金属材料经锻压后，其组织和性能都得到改善，特别是铸造组织。通过压力加工或锻造后，其内部的缺陷（如微裂纹、气孔、缩松等）得到压合，使其结构致密，细化晶粒，力学性能大大提高。

与铸件、焊件相比，锻压加工一般只能获得形状较简单的制件毛坯。

### 3.2 压力加工主要方法

| 方法 | 描述 |
|------|------|
| **轧制** | 金属通过旋转轧辊的间隙，截面减小、长度增加 |
| **拉拔** | 金属通过模孔拉出，截面减小 |
| **挤压** | 金属在挤压筒中从模孔挤出 |
| **自由锻** | 锤击/压力下金属自由变形 |
| **模锻** | 金属在锻模模膛中成形 |
| **板料冲压** | 模具对板料分离或变形 |

### 3.3 锻造

#### 锻造应用

凡是承受重载的机器零件，如主轴、曲轴、齿轮等，一般采用锻件毛坯。

#### 金属的加热

锻造时金属坯料需加热。加热目的是提高金属的塑性，降低变形抗力，以使金属产生大量的变形。

- 一般金属材料的可锻性常用塑性和变形抗力来衡量
- 随着含碳量的提高，金属材料的可锻性下降
- 工业纯铁、低碳钢的可锻性最好；中碳钢、高碳钢、铸铁、硬质合金、有色金属等可锻性较差
- 金属材料加热后，随着温度升高，强度、硬度下降，塑性、韧性提高

#### 锻造温度

加热温度不能过高，超过一定温度后金属易出现氧化、脱碳、过热和过烧等缺陷。加热最高温度以不出现过热为前提，即**始锻温度**。当温度降低到一定程度，金属塑性变差，难以继续变形且易产生裂纹，必须停止锻造重新加热，即为**终锻温度**。

| 钢种 | 始锻温度 | 终锻温度 |
|------|---------|---------|
| **45 钢** | $1150 \sim 1200^\circ\text{C}$ | $800^\circ\text{C}$ |
| **低碳钢** | 约 $1200 \sim 1250^\circ\text{C}$ | 约 $800^\circ\text{C}$ |

锻造温度范围 = 始锻温度 − 终锻温度

#### 锻造工艺分类

自由锻、胎模锻和模锻等。

#### 自由锻基本工序

镦粗、拔长、冲孔、弯曲、扭转、错移、切割等。前 3 种应用得最多。

- 自由锻有手工锻和机器锻两种
- 自由锻设备有空气锤、蒸气-空气锤和水压机等

### 3.4 板料冲压

板料冲压是在室温下，利用安装在压力机上的模具，对板料施加压力，使其产生变形或分离的工艺过程，也称为**冷冲压**。

| 工序类别 | 具体方法 |
|---------|---------|
| **分离工序** | 剪切、冲裁等 |
| **变形工序** | 弯曲、拉深、翻边等 |

### 3.5 关键概念

- **加工硬化**：冷变形使金属强度硬度升高、塑性韧性下降
- **再结晶**：加热到再结晶温度以上，消除加工硬化

## 第四章 焊接

### 4.1 焊接概述

焊接是通过加热或加压（或两者并用），并且用或不用填充材料，使焊件形成原子结合的一种连接方法。

#### 焊接特点

| 优点 | 缺点 |
|------|------|
| 实现不可拆卸的永久性连接 | 焊接工艺不当会产生缺陷、应力和变形 |
| 节省材料，简化制造工艺，缩短生产周期 | |
| 连接处具有良好的使用性能 | |

#### 焊接应用

- 制造各种金属结构件：桥梁、船体、建筑、压力容器、锅炉、车辆、飞机等
- 机器零件毛坯：机架、底座、箱体、吊车车架等
- 修补铸、锻件的缺陷和局部损坏的零件

### 4.2 焊接方法分类

| 大类 | 定义 | 典型方法 |
|------|------|---------|
| **熔化焊** | 接头加热至熔化，不加压 | 手工电弧焊、气焊、CO₂ 保护焊、埋弧焊、氩弧焊、电渣焊 |
| **压力焊** | 施加压力（加热或不加热） | 电阻焊（点焊/缝焊/对焊）、摩擦焊 |
| **钎焊** | 母材不熔化，钎料熔化润湿填充 | 软钎焊（$<450^\circ\text{C}$）、硬钎焊（$>450^\circ\text{C}$） |

#### 焊接性能

原则上各种金属都能焊接，但焊接性能相差很大。焊接性能随着含碳量的增加而下降：

- **最好**：纯铁、低碳钢
- **较差**：高碳钢、铸铁、铸钢、有色金属、异种材料（一般不用来制作焊接结构件）

### 4.3 手工电弧焊

#### 设备

- 弧焊电源：交流焊机（BX1-330）、直流焊机（ZX7-400）

#### 焊条组成

焊条由**焊芯**和**药皮**两部分组成。

| 组成部分 | 作用 |
|---------|------|
| **焊芯** | ① 作为电极传导焊接电流，产生电弧；② 熔化后作为焊缝的填充金属 |
| **药皮** | ① 改善焊接工艺（稳弧）；② 机械保护（造气保护）；③ 冶金处理（造渣） |

#### 焊接参数选择

- 焊条直径：根据被焊工件的厚度和焊接质量来选择
- 焊接电流：根据焊条直径来选择，经验公式：

$$I \approx (30 \sim 50) \, d$$

其中 $d$ 为焊条直径（mm），$I$ 为焊接电流（A）。

#### 正接与反接

- **正接**：工件接正极（适用于厚件）
- 焊接不同的材料应选不同的焊条，并非选用焊条强度级别高的就能提高焊缝质量

#### 优缺点

- **优点**：灵活、全位置焊接
- **缺点**：效率低、质量依赖焊工技能

### 4.4 气焊与气割

#### 气焊

气焊是利用可燃气体燃烧的高温火焰来熔化母材和填充金属的一种焊接方法。焊接时，一般焰芯顶端应距焊件 2～3 mm。通常使用的气体是乙炔和氧气。

#### 三种火焰类型

| 火焰类型 | 氧气/乙炔比例 | 性质 | 适用材料 |
|---------|-------------|------|---------|
| **中性焰** | $\text{O}_2:\text{C}_2\text{H}_2 = 1:1$ | 火焰呈中性，应用最广 | 低中碳钢、合金钢、铜和铝合金等（桥梁、机架等） |
| **碳化焰** | O₂ 不足 | 火焰呈还原性，有增碳作用 | 高碳钢、铸铁、硬质合金等 |
| **氧化焰** | O₂ 过剩 | 火焰呈氧化性 | 黄铜、青铜（一般不采用，仅用于黄铜） |

#### 气焊操作

- 点火时：先微开氧气阀，再开乙炔阀
- 灭火时：先关乙炔阀，再关氧气阀
- 回火时：应先关乙炔阀，再关氧气阀

#### 气焊特点

与电弧焊相比，气焊火焰温度比电弧焊低，热量分散，生产率低，焊接变形大，接头质量差，但气焊火焰可控制，操作方便，灵活性强，不需要电源，可在没有电源的地方应用。

气焊适用于焊接厚度为 3 mm 以下的低碳钢薄板、高碳钢、铸件、硬质合金、铜、铝等有色金属及合金。

#### 气割

气割是利用某些金属在纯氧中燃烧的原理来实现金属切割的方法。

#### 气割条件（三要素）

1. 金属的**燃点应低于熔点**（低碳钢燃点约 $1350^\circ\text{C}$ < 熔点约 $1500^\circ\text{C}$）
2. 燃烧生成的金属氧化物的**燃点应低于金属本身的熔点**
3. 金属燃烧时产生大量的热，且金属本身**导热性要低**

#### 不能气割的材料

满足条件的金属材料有低、中碳钢和低合金钢；而**高碳钢、铸铁、高合金钢及铜、铝等有色金属及合金，均难以进行气割**：

- 不锈钢：氧化物熔点高
- 铝/铜：导热快、燃点 > 熔点

### 4.5 气体保护焊

| 类型 | 保护气体 | 特点 | 适用 |
|------|---------|------|------|
| **CO₂ 保护焊** | CO₂ | 成本低，效率高（是手工焊 2～4 倍），飞溅大 | 低碳钢、低合金钢 |
| **TIG（钨极氩弧焊）** | Ar | 焊缝质量极高、无飞溅，效率低 | 薄件、有色（铝/镁/钛）、不锈钢 |
| **MIG/MAG** | Ar / Ar+CO₂ | 效率高于 TIG | 铝铜（MIG）、碳钢（MAG） |

### 4.6 电阻焊

#### 电阻焊特点

低电压、强电流、焊接时间短、不需填充金属、焊接变形小、生产率高、操作简单，易于实现机械化和自动化。

#### 三种基本形式

| 形式 | 描述 | 应用 |
|------|------|------|
| **点焊** | 薄板搭接 | 厚度 4 mm 以下的薄板结构（汽车车身），电流数千至数万 A |
| **缝焊** | 连续点焊 | 厚度 3 mm 以下，要求密封的容器和管道（油箱） |
| **对焊** | 对接棒材/管材 | 直径小于 20 mm、强度要求低的棒材、管材的对焊（钢轨） |

### 4.7 钎焊

钎焊是采用比母材熔点低的金属材料作为钎料，将焊件接头和钎料同时加热到钎料熔化而焊件不熔化，使液态钎料渗入接头间隙并向接头表面扩散，形成钎焊接头的方法。

| 类型 | 钎料熔点 | 接头强度 | 应用 |
|------|---------|---------|------|
| **硬钎焊** | $>450^\circ\text{C}$ | > 200 MPa | 接头受力较大、工作温度较高的焊件 |
| **软钎焊** | $<450^\circ\text{C}$ | < 70 MPa | 受力不大、工作温度较低的焊件（电子元件、精密仪表） |

#### 钎焊特点

与熔化焊相比，加热温度低，接头金属组织和性能变化及焊接变形小，尺寸容易保证；生产率高，易于实现机械化和自动化；可焊接异种金属。但接头强度较低（特别是冲击韧性较低），耐热能力较差。

### 4.8 常见焊接缺陷

焊接缺陷是指焊接接头部位在焊接过程中形成的缺陷，包括：

**气孔、夹渣、未焊透、未熔合、裂纹、凹坑、咬边、焊瘤、烧穿、弧坑**

## 第五章 切削加工基础知识

### 5.1 金属切削加工概述

金属切削加工是通过刀具与工件的相对运动，从毛坯上切去多余的金属，以获得一定的形状、尺寸、加工精度和表面粗糙度都符合要求的零件加工方法。

金属切削加工分为两大类：

- **钳工**：一般由工人手持工具对工件进行切削加工，包括划线、锯削、锉削、攻丝和套扣、刮研、钻孔、铰孔及装配等
- **机械加工**：通过金属切削机床对工件进行切削加工，如车（数车）、铣（数铣）、磨、钻、刨及特种加工等

### 5.2 切削运动

| 运动类型 | 描述 | 车削中的体现 |
|---------|------|-------------|
| **主运动** | 切除金属最基本的运动，速度最高、消耗功率最大 | 工件旋转（车床主轴带动） |
| **进给运动** | 使新的金属层不断投入切削的运动 | 刀具移动（纵向/横向） |

### 5.3 切削用量三要素

| 要素 | 符号 | 单位 | 含义 |
|------|------|------|------|
| **切削速度** | $v_c$（或 $v$） | m/min | 主运动的线速度 |
| **进给量** | $f$ | mm/r | 工件每转一转，刀具沿进给方向移动的距离 |
| **背吃刀量** | $a_p$ | mm | 工件已加工表面与待加工表面之间的垂直距离 |

#### 三要素对刀具耐用度的影响

三要素中对刀具耐用度影响最大的是 $v$（切削速度），其次是 $f$（进给量），最小的是 $a_p$（背吃刀量）。

#### 切削用量选择优先级

在选定合理的刀具后：

- **粗加工**：$a_p \rightarrow f \rightarrow v$（优先选大的背吃刀量，其次进给量，最后切削速度）
- **精加工**：$v \rightarrow f \rightarrow a_p$（优先选高的切削速度，其次进给量，最后背吃刀量，以提高表面质量）

### 5.4 刀具的几何角度

金属切削刀具种类繁多，构造各异。较典型的车刀，其它刀具的切削部分都可看作以车刀为基本形态演变而成。

#### 车刀的组成

车刀由刀头和刀体两部分组成。刀头为切削部分，刀体用来将车刀夹持在刀架上，起支承与传力作用。

刀头一般由**三个面、二个刃和一个尖**组成：

1. 前面
2. 主后面
3. 副后面
4. 主切削刃
5. 副切削刃
6. 刀尖

#### 五个基本角度

| 角度 | 符号 | 测量平面 | 定义与作用 | 取值原则 |
|------|------|---------|-----------|---------|
| **前角** | $\gamma_0$ | 正交平面 | 前面与基面的夹角。增大前角则刀具锋利，切削轻快，但前角过大刀刃强度降低 | 工件材料硬度较低、塑性较好、刀具韧性较好及精加工时取大值；反之取小值。硬质合金车刀一般取 $-5^\circ \sim +25^\circ$ |
| **后角** | $\alpha_0$ | 正交平面 | 主后面与切削平面的夹角。增大后角可减少刀具主后面与工件摩擦，但后角过大刀具强度降低 | 粗加工取小值（$6^\circ \sim 8^\circ$），精加工取大值（$10^\circ \sim 12^\circ$） |
| **主偏角** | $\kappa_r$ | 基面 | 主切削刃与进给运动方向在基面上投影的夹角。增大主偏角可使轴向分力加大、径向分力减小，有利于减小振动，但刀具磨损加快、散热变差 | 一般取 $45^\circ \sim 90^\circ$。工件刚度好、粗加工时取小值；车细长轴取大值 |
| **副偏角** | $\kappa_r'$ | 基面 | 副切削刃与进给运动反方向在基面上投影的夹角。增大副偏角可减小副切削刃与已加工面的摩擦，降低表面粗糙度，防止振动 | 一般取 $5^\circ \sim 15^\circ$。粗加工取大值，精加工取小值 |
| **刃倾角** | $\lambda_s$ | 切削平面 | 主切削刃与基面的夹角。主要作用是控制切屑的流动方向 | $\lambda_s = 0$：切削刃与基面平行；负值：刀尖处于最低点，刀尖强度大，切屑流向已加工表面，用于粗加工；正值：刀尖处于最高点，刀尖强度较低，切屑流向待加工表面，用于精加工。一般取 $-5^\circ \sim +10^\circ$ |

> **总结**：粗加工时选择小的 $\gamma_0$、$\alpha_0$；精加工时选择大的 $\gamma_0$、$\alpha_0$。

### 5.5 刀具材料

刀具切削部分的材料应具有：

1. **高的硬度**
2. **高的耐磨性**
3. **高的热硬性（红硬性）**
4. **足够的强度和韧性**
5. 良好的工艺性

### 5.6 切屑类型

| **崩碎切屑** | 脆性材料（如铸铁） |

### 5.7 常用量具

## 第六章 车削加工

### 6.1 车削概述

车削是机械加工中的主要方法，使用范围很广。车削是利用工件的旋转运动和刀具的直线运动来加工的。

在车床上可加工：内外圆柱面、内外圆锥面、内外螺纹、成形面、端面、沟槽、滚花等。

车加工精度一般 **IT10～IT8**，表面粗糙度 **Ra 6.3～1.6 μm**。

### 6.2 普通车床

#### 车床组成

床身、主轴箱、进给箱、溜板箱、拖板、刀架和尾座等。

#### 车床种类

普通车床、转塔车床、立式车床、数控车床。

### 6.3 工件装夹方式

| 装夹方式 | 特点 |
|---------|------|
| **三爪卡盘** | 自定心，装夹方便，适合圆形、六角形工件 |
| **四爪卡盘** | 单动，可装夹不规则形状工件，找正麻烦但夹紧力大 |
| **顶尖装夹** | 一夹一顶 / 双顶尖，适合轴类零件 |
| **花盘装夹** | 适合不规则形状、大直径盘类零件 |
| **心轴装夹** | 以孔定位加工外圆，保证同轴度 |
| **中心架及跟刀架** | 加工细长轴时增加刚性，防止弯曲变形 |

### 6.4 车刀的安装

1. **车刀刀尖应与工件中心线等高**
   - 刀尖高于工件中心线：前角增大而后角减小，车刀后面与工件之间的摩擦增大
   - 刀尖低于工件中心线：前角减小，后角增大，切削不顺利
2. **车刀刀杆轴线应与工件表面垂直**：否则会引起主偏角和副偏角发生变化
3. **刀杆伸出长度不宜太长**：以免发生刀杆振动，一般伸出长度不超过刀杆厚度的 1.1～1.5 倍

### 6.5 基本车削工艺

#### 车外圆

最基本的车削加工。

#### 车端面

车端面时应注意：

1. **车刀刀尖应对准工件中心**：否则将在端面中心处车出凸台，并易蹦坏刀尖
2. **切削速度变化**：车端面时切削速度由外向中心逐渐减少，会影响端面粗糙度，工件转速应比车外圆略高
   - 45° 右偏刀车端面由外向中心车削时，凸台是瞬间车掉，易产生振动、损坏刀具，因此切削接近中心时应放慢进给速度
   - 有孔工件车端面时，常用右偏刀由中心向外进给，切削厚度较小，刀刃有前角，切削顺利，粗糙度小
3. **大直径端面**：为避免因车刀受刀架移动产生凸出或凹进，可将拖板固定在床身上横向切削，背吃刀量用小刀架调节

#### 车圆锥

| 方法 | 原理 | 特点 | 适用 |
|------|------|------|------|
| **转动小拖板法** | 小刀架扳转 $\alpha/2$，手动进给 | 操作简单，可加工任意锥角的内、外圆锥面；但加工长度受限，只能手动进给 | 短锥面，粗糙度 12.5～3.2 μm |
| **偏移尾架法** | 尾座顶尖横向偏移距离 $S$，使工件轴线与主轴中心线交角等于锥角的 1/2 | 可加工较长锥面，可手动或自动进给；但不能车削内圆锥面，尾架偏移量受限 | 长锥面，锥度不大（$\alpha < 8^\circ$），粗糙度 6.3～1.6 μm |
| **靠模法（靠尺法）** | 使用锥度靠模 | 可自动进给，精度较高 | 批量生产 |
| **宽刀法** | 用宽刃车刀直接车出 | 效率高，但需刀具刃磨准确 | 短锥面、批量生产 |

#### 车螺纹

#### 保证正确的牙形角

1. **车刀的刀尖角应等于牙形角 $\alpha$**：使车刀切削部分形状与螺纹截面形状相吻合。为保证这一要求，应取**前角 $\gamma_0 = 0$**。粗加工时为改善切削条件，可用带有正前角的车刀车削
2. **正确地安装车刀**：车刀刀尖必须与工件中心等高，否则螺纹截面将有改变。车刀刀尖角的等分线必须与工件的轴线相垂直，应用对刀样板进行对刀

#### 保证工件的螺距

保证螺距的基本方法是：在工件旋转一周时，车刀准确移动一个螺距。调整车床和交换齿轮，根据公式计算出的交换齿轮必须符合下列条件：

$$Z_1 + Z_2 \geq Z_3 + (15 \sim 20)$$
$$Z_3 + Z_4 \geq Z_2 + (15 \sim 20)$$

## 第七章 孔加工（钻削与镗削）

### 7.1 钻削

钻削加工是钻头作旋转的主运动，同时钻头本身又作轴向的进给运动，在实体材料上加工孔的方法。

钻床是孔加工机床，可以完成钻孔、扩孔、锪孔和铰孔等工作。

#### 麻花钻

- 有两条对称的主切削刃
- 如刃磨时两条主切削刃不相等，则所钻孔直径要大于钻头直径
- 钻头角度：顶角（锋角）$118^\circ$

#### 钻孔特点

- 钻孔过程最容易发生引偏，使孔径增大
- 钻孔前在孔中心要打样冲眼，孔中心打得大一些可起到钻孔时不易偏离中心的作用
- 钻孔属**粗加工**，精度一般 **IT13～IT11**，表面粗糙度 **Ra 12.5～6.3 μm**

### 7.2 扩孔

用扩孔钻将已有孔（如铸出、锻出或钻出的孔）扩大加工的方法。

- 扩孔属**半精加工**，精度一般为 **IT9～IT10**，表面粗糙度为 **Ra 3.2～6.3 μm**
- 扩孔可以作为孔加工的最后工序，或作为铰孔前的准备工序

### 7.3 铰孔

当孔的精度和表面粗糙度要求较高时，采用铰孔。铰孔是对工件上已有孔进行精加工的方法之一。

| 铰孔类型 | 精度 | 表面粗糙度 |
|---------|------|-----------|
| **粗铰** | IT8～IT7 | Ra 1.6～0.8 μm |
| **精铰** | IT7～IT6 | Ra 0.8～0.4 μm |

> 注：部分资料标注铰孔精度为 IT6～IT7，Ra 0.4～0.8 μm，以实际课程要求为准。

### 7.4 镗孔

镗孔是对工件上已有孔进行精加工的方法之一。

- 镗孔一般精度为 **IT8～IT7**，表面粗糙度为 **Ra 0.8～1.6 μm**
- 精镗时可达精度 **IT7～IT6**，表面粗糙度为 **Ra 0.2～0.8 μm**
- 镗孔主要用于箱体、机架等结构复杂的中、大型零件上孔与孔之间的加工，容易保证孔与孔之间、孔与基准面之间的尺寸精度及位置精度

> **重要区别**：钻、扩、铰只能保证孔本身的精度，而不能保证孔与孔之间的尺寸精度。此时可利用夹具（如钻模）或**镗孔**来保证。

### 7.5 孔加工精度对比汇总

| 加工方法 | 加工类型 | 精度等级 | 表面粗糙度 Ra |
|---------|---------|---------|-------------|
| 钻孔（麻花钻） | 粗加工 | IT13～IT11 | 12.5～6.3 μm |
| 扩孔 | 半精加工 | IT10～IT9 | 6.3～3.2 μm |
| 铰孔 | 精加工 | IT7～IT6 | 0.8～0.4 μm |
| 镗孔 | 精加工 | IT8～IT7（精镗 IT7～IT6） | 1.6～0.8 μm（精镗 0.8～0.2 μm） |

## 第八章 铣削与刨削加工

### 8.1 铣削概述

最常用的铣床是万能立式铣床和万能卧式铣床。

可铣削：平面、成形面、台阶、键槽、T 形槽、齿轮、镗孔等。

### 8.2 铣刀的种类

常用铣刀有：圆柱铣刀、端铣刀、直柄铣刀、圆锥铣刀、三面刃铣刀、盘铣刀等。

端铣刀可铣削平面、斜面和垂直面等。

### 8.3 铣床主要附件

| 附件 | 用途 |
|------|------|
| **平口钳** | 中小型工件装夹；大中型工件则用压板、角铁和 V 型块紧压在工作台上 |
| **回转工作台** | 主要用于对较大工件进行分度，或加工具有圆弧表面和圆弧形腰槽的零件 |
| **万能分度头** | 用于各种齿槽及多面体工件的铣削加工 |

#### 万能分度头

分度公式：

$$N = \frac{40}{Z}$$

其中 $N$ 为分度头手柄转数，$Z$ 为工件等分数（如齿轮齿数）。40 为分度头的定数（传动比）。

### 8.4 铣削特点

铣削与刨削相比，除狭长平面外，生产率高。主要原因：

- 铣刀由多齿和多刃组成，铣削工作同时由参加工作的几个刀齿和刀刃承担
- 切削用量大
- 刀齿与工件接触时间短，刀具冷却条件好
- 铣刀的耐用度高

所以铣削具有较高的生产率及加工精度。

### 8.5 铣齿

- 单件小批量生产
- 精度较低

## 第九章 磨削加工

### 9.1 磨削概述

在磨床上用砂轮切削工件表面的方式称为磨削加工。磨削加工通常用于零件的**精加工**。

- 一般加工精度为 **IT5～IT7**
- 表面粗糙度为 **Ra 0.2～0.8 μm**
- 磨削不仅可加工钢、铸铁等一般材料，还可以加工一般刀具难以加工的材料（如淬火钢、硬质合金等）

### 9.2 磨削特点

1. **能加工硬度很高的材料**：如淬硬钢、硬质合金等。因为砂轮磨粒本身具有很高的硬度和耐热性
2. **能获得高精度和低粗糙度的加工表面**：由砂轮和磨床特性决定
   - 磨粒圆角半径小，分布稠密且多为负前角
   - 磨削速度高，每个磨刃切削量小
   - 磨床刚度好，转动平稳，可作微量进给
3. **磨削温度高**：由于剧烈的摩擦产生大量磨削热，使磨削区温度很高。这会使工件表面产生磨削应力和变形，甚至造成工件表面烧伤。因此磨削时必须注入大量冷却液，以降低磨削温度。冷却液还可起到排屑和润滑作用

### 9.3 磨削过程

磨削过程是**切削、刻划和滑擦**三种过程的综合。

### 9.4 磨削运动

| 运动类型 | 描述 |
|---------|------|
| **主运动** | 砂轮的旋转运动 |
| **进给运动** | 工件的旋转运动、砂轮的纵向移动、砂轮的径向进给运动 |

### 9.5 磨削时径向力大

磨削时径向力很大，这会造成机床—砂轮—工件系统的弹性退让，使实际切深小于名义切深。因此，磨削将要完成时，应不进刀进行**光磨**，以消除误差。

### 9.6 砂轮的"自锐性"

磨粒磨钝后，其磨削力也随之增大，致使磨粒破碎或脱落，重新露出锋利的刃口。这种特性称为"自锐性"。

- 自锐性能使磨削在一定时间内正常进行
- 超过一定时间后，应进行人工修磨（修整），以免磨削力增大引起振动及损失表面质量

### 9.7 砂轮的硬度

砂轮的硬度是指在外力作用下磨粒脱落的难易程度。易脱落的称之为软，反之为硬。

| 选择原则 | 砂轮硬度 |
|---------|---------|
| 磨削**软材料** | 选用**硬砂轮** |
| 磨削**硬材料** | 选用**软砂轮** |
| **粗磨** | 选用**软砂轮** |
| **精磨** | 选用**硬砂轮** |

## 第十章 钳工

### 10.1 钳工概述

钳工是手持工具对工件进行加工的方法。

**基本操作**：划线、錾削、锯削、锉削、攻丝和套扣、刮削及装配等。

### 10.2 划线

划线是在毛坯上划出加工界限。

#### 划线种类

1. **平面划线**：在工件的一个平面上划线
2. **立体划线**：在工件三个坐标方向上划线

#### 划线基准

零件上用来确定点、线、面位置的依据，作为划线依据的基准，称为划线基准。

### 10.3 錾削

手锤打击錾子去除材料的加工方法。

### 10.4 锯削

#### 锯条

- 锯条用碳素工具钢制成，并经淬火及回火处理，硬度可达 58～62 HRC
- 锯条规格用其两端安装孔的距离来表示，常用锯条长 300 mm、宽 12 mm、厚 0.8 mm
- 锯条按齿距分为**粗齿、中齿和细齿** 3 种

#### 锯条的安装

- 锯条装在锯弓上，**锯齿向前**
- 松紧适当，不能有歪斜和扭曲，否则锯削时易折断

#### 锯条的选用

| 锯条类型 | 适用场景 |
|---------|---------|
| **粗齿锯条** | 软材料（如铜、铝等有色金属）及厚工件 |
| **中齿锯条** | 普通钢、铸铁及中等厚度的工件 |
| **细齿锯条** | 较硬的材料（如中碳钢、合金钢等）或较薄的工件（如板料、钢管等） |

> 原则：软、厚工件 → 粗齿；硬、薄工件 → 细齿。

#### 锯削方法

- 锯削时应注意起锯、锯削压力和往返长度
- 起锯角应**小于 15°**，并用左手拇指靠住锯条
- 锯弓作往复运动，左手施力，右手推进，用力要均匀
- 返回时锯条轻轻地滑过加工面，速度不宜太快
- 锯削开始和终了时的压力和速度均应减少
- 锯条长度应充分利用，往返长度不应少于 2/3，以免局部过早磨损
- 锯缝如有歪斜，不可强扭，应将工件翻转 90°，重新起锯

### 10.5 锉削

用锉刀从工件表面锉掉多余金属的加工方法称为锉削。锉削可提高工件的尺寸精度和降低表面粗糙度，是钳工最基本的操作方法。

可锉削平面、曲面、沟槽、内外圆弧面和复杂形状表面等。

#### 锉刀

- 锉刀用碳素工具钢制造，并经淬火及回火处理，硬度可达 58～62 HRC 以上
- 锉刀规格以其工作部分的长度来标示，有 100 mm、150 mm、…、400 mm 等 7 种
- 锉刀面的齿纹有单齿纹和双齿纹之分

#### 锉刀分类

按用途分为：普通锉刀、整形锉刀（又称什锦锉）和特种锉刀。

按齿纹分为：

| 齿纹类型 | 齿密度（每 10 mm） | 用途 |
|---------|-------------------|------|
| **粗齿** | 4～12 齿 | 粗加工及锉削较软的材料（如铜、铝等） |
| **中齿** | 13～24 齿 | 粗锉后的加工 |
| **细齿** | 30～40 齿 | 锉光表面及锉削较硬的材料（如钢、铸铁等） |
| **油光锉** | 40 齿以上 | 精锉后的表面修光 |

#### 锉刀的种类（按截面形状）

平锉、方锉、圆锉、半圆锉、三角锉。

#### 锉削方法

1. 工件装夹在台虎钳口中间，被锉削表面距钳口的距离不要太高
2. 以保持锉刀水平为原则，根据锉刀规格不同握法不同。锉削时两手在锉刀上施加的力的大小是变化的，其原则是保持水平，即以工件为支点形成力的杠杆平衡
3. **锉平面**方法：
   - **顺向锉**：用于精加工锉平和锉光
   - **交叉锉**：用于粗加工，生产率高
   - **推锉**：主要用于修光，适用于锉削细长工件及台阶面
4. **锉圆弧**方法：
   - **滚锉**：锉刀顺圆弧切向摆动锉削，常用于精锉外圆弧面
   - **顺锉**：锉刀垂直圆弧面轴向运动，适用于粗锉

### 10.6 钻孔、扩孔、铰孔（钳工）

- **钻孔**：麻花钻，钻头角度（顶角 118°）
- **扩孔**：半精加工
- **铰孔**：提高孔精度（IT7～8 级）

### 10.7 攻丝与套丝

- **攻丝**：用丝锥在零件的通孔或盲孔上加工**内螺纹**
- **套丝**：用板牙在圆杆或圆管上加工**外螺纹**

#### 攻丝

攻丝前需要钻孔，一般钻孔的孔径应略大于螺纹内径。

**底孔直径经验公式**：

| 材料类型 | 底孔直径公式 |
|---------|-------------|
| **塑性材料**（钢、紫铜等） | $d = D - P$ |
| **脆性材料**（铸铁、青铜等） | $d = D - (1.05 \sim 1.1)P$ |

其中：$D$ — 螺纹大径（公称直径），$P$ — 螺距，$d$ — 底孔直径。

**攻盲孔（不通孔）螺纹时**：

$$\text{孔的深度} = \text{要求螺纹的长度} + 0.7D$$

**操作要点**：

- 将钻好的孔倒角
- 把头锥装在铰杠上，两手加压（大小合适）进行攻丝
- 注意要保持丝锥垂直，旋转一周后要倒转（断屑）
- 钻通孔螺纹时，注意丝锥切削部分要完全伸出孔端
- 然后用二锥、三锥完善螺孔

丝锥分为头锥、二锥（有的还有三锥）。

#### 套丝

套丝前应检查圆杆直径。圆杆直径太大，板牙难以套入；太小则套出的螺纹牙形不完整。一般圆杆的直径要略小于螺纹外径。

**圆杆直径经验公式**：

$$D = d - 0.13P$$

其中：$d$ — 外螺纹外径，$P$ — 螺距，$D$ — 圆杆直径。

一般材料韧性愈大，则圆杆直径愈小。

**操作要点**：

- 套丝前，圆杆的端面要倒角，倒角深度要超过螺纹全深
- 套丝的操作与攻丝很相似，两手施力应均匀，保持板牙架手柄与圆杆垂直

### 10.8 刮削

高精度表面加工（导轨、轴瓦等）。

### 10.9 装配

组件装配、部件装配、总装配。

## 第十一章 数控加工

### 11.1 数控基础概念

#### 数控机床概述

数控机床综合应用了自动控制、计算机、精密测量和传动元件、结构设计等技术，是一种高效、柔性加工的机电一体化设备。

#### 数控机床组成

| 组成部分 | 内容 |
|---------|------|
| **主机** | 数控机床的主体，包括床身、立柱、主轴、进给机构等 |
| **CNC 装置** | 数控机床的核心，包括硬件（电路板、显示器、键盘、纸带阅读机等）以及相应的软件 |
| **驱动装置** | 数控机床执行机构的驱动部件，包括主轴驱动单元、进给驱动单元、主轴电机等 |
| **辅助装置** | 以及编程机及其他一些附属设备 |

#### 数控机床分类

- 按控制方式：点位控制机床、直线控制机床、轮廓控制机床
- 按数控系统：数字控制（NC）、计算机数字控制（CNC）、直接数字控制（DNC）

#### 相关概念

| 缩写 | 全称 | 含义 |
|------|------|------|
| **NC** | Numerical Control | 数字控制 |
| **CNC** | Computer Numerical Control | 计算机数控 |
| **FMS** | Flexible Manufacturing System | 柔性制造系统 |
| **CIMS** | Computer Integrated Manufacturing System | 计算机集成制造系统 |

#### 数控编程步骤

1. 分析零件图形和工艺处理
2. 数字处理
3. 编写零件加工程序单、输入数控系统及程序检验

#### 数控编程方法

- **手工编程**：适用于点加工或几何形状不太复杂的零件
- **自动编程**：用计算机把人们易懂的零件程序改成数控机床执行的数字加工程序，数控编程的大部分工作由计算机来完成

### 11.2 数控指令代码

数控系统指令代码中，最基本的是 **G、S、M、T** 指令代码。

| 指令 | 功能 | 说明 |
|------|------|------|
| **G 指令** | 准备功能 | 描述数控装置作某一操作的准备功能，如直线插补、圆弧插补等。由代码"G"和两位数字组成，从 G00～G99 共 100 种 |
| **S 指令** | 主轴转速功能 | 由"S"和其后若干位数字组成 |
| **M 指令** | 辅助操作功能 | 两类：① 主轴的正反转、开停，冷却液的开关等；② 程序控制指令，进行子程序调用、结束等 |
| **T 功能** | 刀具功能 | 用于选择刀具和进行刀具补偿。由代码"T"和若干位数字组成 |

### 11.3 数控车削（数车）

#### 坐标系

- **机床坐标系**：固定
- **工件坐标系**：G54～G59 可设定
- **绝对坐标 / 增量坐标**：增量坐标用 U/W 表示

#### 插补

- 直线插补（G01）
- 圆弧插补（G02/G03）

#### 刀补

刀具补偿（T 指令 + 刀偏表）。

#### 核心 G 代码（FANUC 系统）

| 指令 | 功能 | 备注 |
|------|------|------|
| **G00** | 快速定位 | 不可切削 |
| **G01** | 直线插补 | 需指定 F 进给 |
| **G02/G03** | 顺/逆时针圆弧插补 | R 或 I/K |
| **G71** | 外圆/内孔粗车循环 | 轴向进刀，径向切削，棒料 |
| **G72** | 端面粗车循环 | 径向进刀，轴向切削，盘类 |
| **G73** | 封闭轮廓粗车循环（仿形） | 锻/铸件，支持凹坑 |
| **G70** | 精车循环 | 配合 G71/G72/G73 |
| **G92** | 螺纹切削循环 | 需多次调用分层 |
| **G41/G42/G40** | 刀尖半径补偿（左/右/取消） | — |
| **G90/G91** | 绝对/增量编程 | — |
| **G96/G97** | 恒线速/恒转速 | 螺纹用 G97 防乱牙 |
| **M03/M05** | 主轴正转/停 | — |
| **M08/M09** | 冷却液开/关 | — |
| **M30** | 程序结束并复位 | — |

#### G71 参数含义

- U（$\Delta d$）：背吃刀量
- U（$\Delta u$）：X 方向余量（直径值）
- W（$\Delta w$）：Z 方向余量

#### G92 螺纹切削

- 螺距 = 导程（单线螺纹）
- 需分层多次调用
- **螺纹不乱牙的保证条件**：G97 恒转速 + 相同 Z 起点

#### i5 系统专有指令（沈阳机床）

i5 数控车削系统由沈阳机床自主研发，基于 PC 的数控技术，采用 EtherCAT 实时数字总线技术，配备自主研发的 HSHA 系列全数字伺服驱动器。

| 指令 | 功能 | 参数说明 |
|------|------|---------|
| **CYCLE95** | 轮廓粗/精加工循环（SIEMENS 风格），替代 G71+G70 | 轮廓子程序名、进给深度、精加工余量、轮廓类型（1=外圆/2=内孔/7=端面） |
| **CYCLE97** | 螺纹切削循环 | 螺纹直径、螺距、螺纹长度、导入/导出长度、牙高、切削次数 |

**螺纹牙高计算公式**：

$$h = 0.5413 \times P$$

其中 $P$ 为螺距。

**MDA 模式**：手动数据输入，单段执行。

**对刀**：建立工件坐标系，刀偏表管理。

### 11.4 数控铣削（数铣）

#### 数控铣削概述

数控铣床可完成：平面铣削、轮廓铣削、曲面铣削、钻孔、镗孔、攻丝。

#### 坐标系

- Z 轴与主轴轴线平行（刀具主轴方向）
- X 轴为水平方向（操作者左右）
- Y 轴由右手定则确定

#### 常用代码

| 指令 | 功能 |
|------|------|
| **G00** | 快速定位 |

## 第十三章 电火花线切割（WEDM）

### 13.1 特种加工概述

#### 特种加工需求

1. 解决各种难加工材料的问题
2. 解决各种特殊复杂表面的加工问题
3. 解决各种具有特殊要求的零件的加工问题

#### 特种加工特点

- 不是主要依靠机械能通过刀具来切除金属或非金属材料，而是主要用其他能量形式（电能、化学能、光能、声能、热能或与机械能组合等）直接加工零件
- 加工用的工具材料可以低于被加工材料的硬度
- 加工过程中工具和工件之间不存在显著的机械切削力

#### 特种加工的能源形式分类

| 能量形式 | 加工方法 |
|---------|---------|
| 电、热能 | 电火花加工、电子束加工、等离子弧加工 |
| 电、机械能 | 离子束加工 |
| 电、化学能 | 电解加工、电解抛光 |
| 电、化学、机械能 | 电解磨削、电解珩磨、阳极机械磨削 |
| 光、热能 | 激光加工 |
| 化学能 | 化学加工、化学抛光 |
| 声、机械能 | 超声波加工 |
| 机械能 | 磨料喷射加工、磨料流加工、液体喷射加工 |

### 13.2 电火花加工概述

电火花加工是利用工具电极和工件两极之间脉冲放电时产生的电腐蚀现象对工件进行尺寸加工的加工方法。

#### 电火花加工主要特点

- 脉冲放电的能量密度很高，可以加工用常规机械加工方法难以加工或无法加工的材料和形状
- 加工时工具电极与工件不直接接触，两者之间的宏观作用力小
- 不受工具和工件刚度限制，有利于实现微细加工
- 工具电极材料不需比被加工的工件材料硬，因此工具电极制造容易

#### "以柔克刚"原理

软工具电极加工硬工件（如紫铜加工淬火钢），属不接触加工，无宏观切削力。

#### 电火花成型加工精度与粗糙度

| 加工类型 | 精度 | 表面粗糙度 Ra |
|---------|------|-------------|
| 精加工 | 0.01 mm | 0.63～1.25 μm |
| 微精加工 | 0.002～0.004 mm | 0.04～0.16 μm |

### 13.3 电火花线切割基本原理

#### 定义

利用连续移动的金属丝（钼丝）作工具电极，与工件之间脉冲放电产生电腐蚀，实现尺寸加工。

#### 蚀除机理

两极在绝缘液（皂化液）中靠近 → 极间介质击穿 → 放电通道形成 → 瞬时高温（$>10000^\circ\text{C}$）→ 金属熔化/气化。

#### 三个必要条件

1. **钼丝与工件保持一定放电间隙**（过大不放电，过小短路）
2. **有一定绝缘性的液体介质**（皂化液：绝缘 + 排屑 + 冷却）
3. **脉冲电源**（脉冲性、间歇性放电）

### 13.4 线切割与电火花成型加工对比

| 对比项 | 线切割（WEDM） | 电火花成型 |
|-------|----------------|-----------|
| 工具电极 | 连续移动的线电极（钼丝） | 成型电极（紫铜/石墨） |
| 运动方式 | X-Y 两方向伺服进给 | 单方向伺服进给 |
| 工作液 | 皂化液 | 专用煤油 |
| 应用 | 冲模、异形孔、窄缝、样板 | 型腔模（注塑模/压铸模） |

### 13.5 线切割机床组成

| 组成部分 | 内容 |
|---------|------|
| **机床主体** | 床身、丝架、走丝机构、X-Y 数控工作台 |
| **工作液系统** | 工作液由泵压送到加工区外围，由钼丝带入加工区，经过滤后循环使用 |
| **高频脉冲电源** | 产生高频矩形脉冲，阳极加至工件，阴极加至电极丝（钼丝）；脉冲幅度、脉冲间隔和脉冲宽度等可调节 |
| **数控和伺服系统** | 以专用计算机为核心，进行插补运算、判别；变频进给系统将放电间隙平均电压反馈给控制系统，调节工作台速度 |

钼丝绕在贮丝筒上，经过丝架上的导轮来回高速走动，贮丝筒由电机直接驱动，通过限位开关控制正、反向。工件固定在 X-Y 数控工作台上，由步进电机驱动作伺服进给移动。

### 13.6 3B 格式编程（手工编程核心）

3B 格式是国内常用的线切割编程格式：

$$\text{B X B Y B J G Z}$$

| 字段 | 含义 | 规则 |
|------|------|------|
| **B** | 分隔符 | 必写 |
| **X** | X 坐标值 | 直线：终点相对起点；圆弧：起点相对圆心；单位 μm |
| **Y** | Y 坐标值 | 同上 |
| **J** | 计数长度 | 轨迹在计数方向投影总长（跨多象限则求和） |
| **G** | 计数方向 | Gx 或 Gy |
| **Z** | 加工指令 | L1～L4（直线）、SR1～SR4（顺圆）、NR1～NR4（逆圆） |

#### 计数方向选择规则

- **直线**：取终点坐标绝对值**较小**的轴
  - $|X_e| < |Y_e|$ → Gx
- **圆弧**：取终点坐标绝对值**较大**的轴
  - $|X_e| > |Y_e|$ → Gx

> **关键注意**：线切割编程坐标系只有**相对坐标系**，每段都要把原点移到起点/圆心。这是与数控车床的重要区别。

### 13.7 快走丝 vs 慢走丝

| 对比项 | 快走丝（WEDM-HS） | 慢走丝（WEDM-LS） |
|-------|-------------------|-------------------|
| 走丝速度 | 8～12 m/s | 0.001～0.2 m/s |
| 电极丝 | 钼丝（循环使用） | 铜丝（一次性） |
| 精度 | 0.01～0.02 mm | 0.001～0.005 mm |
| 粗糙度 Ra | 1.6～3.2 μm | 0.1～0.8 μm |
| 工作液 | 乳化液 | 去离子水 |

### 13.8 电参数影响

| 加工类型 | 参数选择 |
|---------|---------|
| **粗加工** | 大电流、大脉宽、小间隔 → 快速去除 |
| **精加工** | 小电流、小脉宽、大间隔 → 表面粗糙度好 |

#### 极性效应

- **正接**（工件接正极）：精加工
- **反接**（工件接负极）：粗加工速度快

### 13.9 断丝原因

1. 钼丝张力不足/丝振（一般张力 10～15 N）
2. 运丝筒不同轴/导轮磨损
3. 导电块接触不良
4. 工作液脏/排屑不畅
5. 脉冲参数过大

### 13.10 线切割零件图形要求

## 第十四章 激光加工

### 14.1 激光基础

#### LASER 全称

**LASER = Light Amplification by Stimulated Emission of Radiation**（受激辐射光放大）

#### 原理

激光束具有高亮度、高方向性，通过光学系统聚焦成微细光束（几 μm～几十 μm），获得极高能量密度，使材料瞬间熔化/气化。

单位换算：$1\ \text{mm} = 1000\ \mu\text{m}$

### 14.2 激光器基本结构

激光器三要素：**工作物质 + 光学谐振腔 + 泵浦**

| 组成部分 | 说明 |
|---------|------|
| **工作物质（激光管）** | 放电管 + 水冷套 + 储气管；CO₂ 激光器最常用 |
| **光学谐振腔** | 全反射镜 + 部分反射镜，平凹腔 |
| **泵浦（激励能源）** | 连续直流电源激发 |

### 14.3 激光器分类（按工作物质）

1. **固体激光器**（晶体/玻璃）
2. **气体激光器**（CO₂ — 工业最常用）
3. **液体激光器**
4. **半导体激光器**
5. **自由电子激光器**

### 14.4 激光切割特点

1. **效率高、速度快**（数控工作台）
2. **切割质量好**：切口细窄、精度 ±0.05 mm、表面粗糙度仅几十 μm
3. **非接触加工**：无刀具磨损，不需更换"刀具"
4. **可切割材料广**：金属 + 非金属（亚克力/木板/塑料/皮革/布料等）
5. **脉冲激光 → 金属材料；连续激光 → 非金属材料**

### 14.5 CO₂ 激光技术参数

| 参数 | 值 |
|------|-----|
| 波长 | 10.64 μm 或 9.3 μm |
| 切割补偿（亚克力） | 0.1 mm |
| 切割补偿（木板） | 0.1～0.3 mm（依厚度材质差异） |

> **不能切割 PVC 等带腐蚀性材料**（产生有毒气体，腐蚀设备）。

### 14.6 CO₂ 射频管 vs 玻璃管

| 对比项 | 射频管 | 玻璃管 |
|-------|--------|--------|
| 价格 | 高（>2 万） | 低（几千） |
| 光斑 | 小、圆、均匀（TEM00） | 模式较差，光斑大 |
| 寿命 | 3～7 年（可充气重复使用） | 0.5～1 年（不可重复） |
| 稳定性 | 高 | 较差 |

### 14.7 激光安全

| 危害类型 | 说明 |
|---------|------|
| **对人眼伤害** | 角膜和视网膜损伤（需佩戴防护眼镜） |
| **对皮肤** | 红外波段可致烧伤，紫外可致皮肤癌 |
| **电学危害** | 高压系统有致命电击风险 |
| **火灾危害** | 激光直接照射或反射可引燃易燃品 |

### 16.5 差速小车运动学

#### 运动学建模假设

- 车体为刚体
- 纯滚动无滑动
- 无侧滑
- 水平面运动
- 总维数 3（$x, y, \theta$）

#### 核心公式

- **前进/后退**：

$$M_1\_\text{Speed} = K_1 \times \text{FBValue}, \quad M_2\_\text{Speed} = K_1 \times \text{FBValue}$$

- **左转/右转**：

$$M_1\_\text{Speed} = K_2 \times \text{LRValue}, \quad M_2\_\text{Speed} = -K_2 \times \text{LRValue}$$

- **混合（边走边转）**：

$$M_1\_\text{Speed} = K_1 \times \text{FBValue} + K_2 \times \text{LRValue}$$
$$M_2\_\text{Speed} = K_1 \times \text{FBValue} - K_2 \times \text{LRValue}$$

### 16.6 两大子任务

| 子任务 | 描述 |
|-------|------|
| **WiFi 遥控绕桩** | 手机 APP 通过 WiFi 控制小车绕桩 |
| **自主巡线** | 灰度传感器检测黑线，有限状态机法控制 |

### 16.7 灰度传感器巡线原理

- 一只发光二极管 + 一只光敏二极管
- 不同颜色反射率不同 → 检测深浅
- 黑（深）色输出 1，白（浅）色输出 0
- 三传感器（左中右）共 $2^3 = 8$ 种状态组合 → 对应动作策略

### 16.8 转弯半径

- 直角弯处曲率半径 $R = 0$，曲率 $\kappa = \infty$
- 过弯需差速控制：`RunMotors(150, -150)` — 原地自转

### 16.9 millis() 函数

- 获取 Arduino 开机后运行时间（毫秒）
- 最长约 50 天后溢出归零
