指南

写博客、推链接、传图片的完整教程

I IVY ·2026 年 8 月 9 日·10 分钟

这篇教程写给未来的自己，也写给任何想在这套博客上发内容的同学。全部是纯静态操作：复制一个文件 → 粘贴内容 → 登记元数据 → git 推送。看完你就会发文章、加链接、传图片和音频了。

你需要的东西 一个 Git 客户端（或命令行），和一个能编辑 HTML 的文本编辑器（VS Code / Sublime / 记事本都行）。

一、怎么发一篇新文章

这套博客里，一篇文章 = 一个 HTML 文件 + 一行元数据。

第 1 步：复制模板

打开 posts/ 文件夹，把任意一篇文章（推荐 why-i-write.html）复制一份，重命名为你的文章名，例如：

posts/我的第一篇笔记.html

也可以直接用英文短横线命名，更稳（避免中文文件名在某些服务器上出问题）：

posts/my-first-note.html

第 2 步：改标题和头部信息

在文件顶部，把 <title>、<meta name="description"> 改成你的标题和一句话简介。

在正文区的 .article-head 里，修改：

<h1>文章标题</h1>
<div class="article-meta">
  <span>2026 年 8 月 9 日</span>
  <span>·</span><span>8 分钟</span>
</div>

第 3 步：写正文

所有正文放在 <div class="prose"> ... </div> 里面，用最普通的 HTML 写就行：

<p>段落文字……</p>
<h2>二级标题</h2>
<h3>三级标题</h3>
<ul><li>列表项 1</li><li>列表项 2</li></ul>
<blockquote>引用别人的话</blockquote>
<strong>加粗</strong> 和 <code>行内代码</code>

第 4 步：登记元数据

打开 assets/js/posts-data.js，在数组里加一条（注意是英文逗号分隔，前一条末尾要有逗号）：

{
  slug: "my-first-note",        // 和文件名一致（不含 .html）
  title: "文章标题",
  cat: "笔记",                  // 笔记 / 资源 / 随笔 / 指南
  date: "2026-08-09",          // 格式 YYYY-MM-DD
  readTime: "8 分钟",
  excerpt: "一句话摘要，会显示在卡片上。",
}

保存后，首页「最新文章」和「全部文章」页面会自动出现这篇，不用改别的文件。

二、怎么加链接

普通链接写在正文里，用 <a> 标签：

这是 <a href="https://github.com/IVY-ZJ" target="_blank" rel="noopener">我的 GitHub</a>。

target="_blank" 表示在新标签页打开，rel="noopener" 是安全写法，建议每次都带上。

资源卡片（网盘 / 下载链接）

如果想在「资源分享」页面放一个醒目的下载按钮，打开 resources.html，复制下面这段再改：

<div class="resource reveal">
  <div class="res-icon" style="background:linear-gradient(145deg,#007AFF,#5856D6)">
    <svg viewBox="0 0 24 24" width="22" height="22" fill="none" stroke="currentColor" stroke-width="1.8"><path d="M4 5h16v14H4z"/><path d="M8 9h8M8 13h6"/></svg>
  </div>
  <div class="res-body">
    <div class="res-title">资料名称</div>
    <div class="res-desc">一句话说明</div>
    <span class="res-code">提取码：xxxx</span>
  </div>
  <a class="btn btn-ios res-action" href="https://pan.baidu.com" target="_blank" rel="noopener">前往网盘</a>
</div>

三、怎么传图片

第一步，把图片放进 assets/img/ 文件夹（或者新建一个 posts/images/ 目录）。第二步，在正文里用 <img> 引用它：

<img src="../assets/img/你的图片.png" alt="图片说明" />

小提示：

  • 路径里的 ../ 是因为文章在 posts/ 子目录里，要先「往上跳一层」才能到 assets/。
  • 图片建议先压缩到 200KB 以内（可用 TinyPNG），否则网页会变慢。
  • 尽量用英文文件名，比如 circuit-diagram.png。

想让图片作为文章顶部的横幅？那是在 HTML 的 <div class="article-cover"> 里通过 CSS 背景图设置的，见 assets/css/style.css 里 .article-cover 相关规则。

四、怎么放音频 / 视频

直接把音频文件放进 assets/audio/（新建），然后在正文里写：

<audio controls preload="metadata">
  <source src="../assets/audio/你的音频.mp3" type="audio/mpeg" />
  你的浏览器不支持音频播放。
</audio>

视频同理（把 assets/video/ 目录建好）：

<video controls preload="metadata">
  <source src="../assets/video/你的视频.mp4" type="video/mp4" />
  你的浏览器不支持视频播放。
</video>

需要图文并茂的「媒体块」样式（带标题的音频/图片卡片），可以复制下面这种写法：

<div class="media">
  <div class="media-block">
    <div class="media-cap">音频标题</div>
    <audio controls preload="metadata">
      <source src="../assets/audio/xxx.mp3" type="audio/mpeg" />
    </audio>
    <p class="media-desc">这段音频讲了什么……</p>
  </div>
</div>

五、怎么分享大文件

GitHub 对单个文件有 100MB 硬限制（超过 50MB 还会警告），所以大文件一律走网盘：上传到百度网盘 / 阿里云盘，把链接贴进文章（见上文「加链接」部分），再把提取码写在旁边。本站的「资源分享」页面就是这样做的。

小文件（< 50MB）可以直接放仓库里下载，用文件行样式：

<div class="file-row">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.8"><path d="M14 3v5h5"/><path d="M6 3h9l4 4v14H6z"/></svg>
  <span class="file-name">大二物理笔记.pdf</span>
  <span class="file-size">12 MB</span>
  <a class="file-link" href="../assets/files/物理笔记.pdf" download>下载</a>
</div>

把文件放到 assets/files/，href 指向它即可。download 属性让浏览器直接下载而不是打开。

六、怎么推到 GitHub（发布上线）

本地改完，打开终端，在博客文件夹里依次执行：

cd 你的博客文件夹
git add -A
git commit -m "写点东西"
git push

如果这是第一次配置仓库（只做一次）：

git init
git add -A
git commit -m "init"
git branch -M main
git remote add origin https://github.com/IVY-ZJ/Ivy-s-Blog.git
git push -u origin main

推送后，GitHub Pages 会自动重新构建，等一两分钟，访问：

https://ivy-zj.github.io/Ivy-s-Blog/

想直接在线编辑？也可以打开仓库网页，找到 posts/ 下的文章点「编辑」图标，改完点 Commit changes —— 更简单，但记得每篇文章都要同步改一下 assets/js/posts-data.js 里的登记信息。

最后一句 写完先 python -m http.server 8000 在本地预览一遍，再推上去，就不会出现「线上打不开」的尴尬了。
