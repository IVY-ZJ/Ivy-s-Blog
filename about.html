这个博客是做什么的

简单说，它有三个用途：

  • 整理学习笔记 —— 课程总结、公式推导、读书方法······
  • 搜集资源 —— 课件、试卷、工具软件，能直接用的东西······
  • 记录思考 —— 偶尔写点随笔。
关于稳定性 本站是纯静态页面，无数据库、无后端依赖，可托管在 GitHub Pages / Vercel / 任意静态空间，常年在线、几乎不会挂。

如何联系我

有疑问、纠错或想交换链接，欢迎发邮件到 ivyzj2000@gmail.com，或在 GitHub 上找我。也欢迎在文章下方留言交流。

技术栈

整个站点用时约一个下午，纯手写 HTML / CSS / JavaScript，遵循 iOS 设计语言(SF Pro 字体、毛玻璃、圆角卡片、系统色彩与明暗模式)。没有用任何框架或构建步骤 —— 这样最稳，也最好改。
