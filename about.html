技术栈

纯手写 HTML / CSS / JavaScript，无任何依赖、无构建步骤。整个站点以 Apple Liquid Glass 语言重制：

  • 设计 token —— Action Blue #0066cc / #2997ff、ink #1d1d1f、parchment #f5f5f7，统一冷暖与对比。
  • Liquid Glass 配方 —— saturate(180%) blur(20-30px) 加半透明填充、1 px hairline 与镜面高光，让顶栏胶囊、登录卡、tags 卡片都能在多源径向渐变背景上保持通透。
  • 字体与排版 —— SF Pro 系统字体栈 -apple-system, "SF Pro Display", "PingFang SC", "HarmonyOS Sans SC"；中文使用 -0.01 ~ -0.025 em 的负字距，正文 17 px / 1.55，标题 650 字重。
  • 导航与组件 —— 浮动 Liquid Glass 胶囊顶栏、可拖动 sheet 抽屉、移动端汉堡菜单、玻璃 CTA、SVG 渐变封面。
  • 主题 —— 跟随系统亮/暗，手动选择写入 localStorage['Ivy-theme']，CSS 变量与 :root[data-theme] 双轨联动。
  • 可托管性 —— 全静态、可放在 GitHub Pages / Vercel / Netlify；不引入 Node 构建、不依赖第三方 CDN；通过 <meta> CSP、蜜罐、登录态限流、frame-buster 做了轻量加固。
