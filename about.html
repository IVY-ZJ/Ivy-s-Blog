这个博客是做什么的

说起来就三件事：

  • 把学过的课整理成笔记。公式怎么来的、踩过哪些坑，都写下来。
  • 攒一些直接能用的东西——课件、试卷、工具软件，免得下次再到处找。
  • 偶尔写点随笔，主要是不吐不快的那些。

如何联系我

文章里有错、想交换友链、或者单纯想问点东西，发邮件到 邮箱，GitHub 上找我也行。文章下面留言也行，看你方便。

技术栈

整个站点手写的 HTML / CSS / JavaScript，没用任何框架、没构建步骤。托管在 GitHub Pages 上就能跑。

视觉是按 Apple 的 Liquid Glass 那一套来的——半透明 + 1px 描边 + 镜面高光，亮暗主题都跟系统走，想手动切也行（写进 localStorage）。字体用的是 SF Pro 系，中文配 PingFang / HarmonyOS Sans。

安全性没做太重：登录态限流、CSP、蜜罐、frame-buster——挡挡脚本小子和爬虫够了，真正的密码学不是我的活。
