## 诗句面板切换动画抖动修复（第六轮）
- 用户反馈：点击换句时面板会有短时间的位置偏移，然后又回正。
- 原因：换句动画 `poetryFlip` 使用 `rotateY` 直接加在 `.poetry-rail` 上，而 `.poetry-rail` 有 `backdrop-filter: blur(12px)`；Chrome 在变换带毛玻璃的元素时会出现重绘/位置抖动。
- 方案迭代：
  - 第一版：把毛玻璃层（`.poetry-rail`）和动画层（`.poetry-inner`）分离，抖动消失，但用户希望毛玻璃和诗句一起旋转。
  - 最终版：保留 `.poetry-inner` 作为布局包裹，但让 `.poetry-rail` 整体旋转，并通过 `will-change: transform` + `backface-visibility: hidden` 把 `.poetry-rail` 提升为独立 GPU 合成层，让毛玻璃模糊被缓存为纹理、随 rotateY 整体旋转，避免每帧重绘背景。
  - `login.css`：
    - `.login-poetry` 加 `perspective: 1000px`，让卡片翻转有真实 3D 透视感。
    - `.poetry-rail` 加 `will-change: transform; backface-visibility: hidden; transform-origin: center center;`，并重新承担 `poetryFlip` 动画。
    - 入场 `poetryEnter` 移到 `.poetry-inner`（纯淡入），避免 rail 动画切换后重播。
  - `login.js`：`bindPoetryFlip()` 恢复为对 `.poetry-rail` 添加/移除 `.flipping`，并在 `animationend` 清理 class。
- 验证：agent-browser 抓取切换前、切换中（~150ms）、切换后三帧，毛玻璃和诗句作为一个整体旋转，卡片中心位置稳定，没有偏移回正现象。
- 产出截图：`preview-r8/09a-rail-before.png`、`09b-rail-mid.png`、`09c-rail-after.png`。

## 第九轮修正：修复拆分后重复显示的 Bug
- 用户截图反馈：拆分后的 32 条诗出现原整句与下句同时显示、内容重复（如「时人不识凌云木直待凌云始道高」旁又显示「直待凌云始道高」）。

### agent-browser 踩坑补记（追加）
- `--executable-path` 是**全局选项**，必须在子命令 `open` 前面：`agent-browser --executable-path "C:\Program Files\Google\Chrome\Application\chrome.exe" open ...`，子命令后会被「daemon already running」警告忽略。
- daemon 已经在跑时改路径不生效，必须 `close --all` 然后再 open（close 输出 "✓ Closed session: default" 但 daemon 进程不一定退出，需要重新 open 才会按新路径启动浏览器）。
- chromium 自带二进制在 Windows 经常 exit code 3，先尝试加 `--args "--no-sandbox"`，或者就用上面 `--executable-path` 切到系统 Chrome。
- `set media dark` 改的是 `prefers-color-scheme` 媒体查询，不改 `data-theme` 属性。本站 CSS 用 `:root[data-theme="dark"]` 显式优先，且依赖 `matchMedia` 回退，所以单独 `set media dark` 不会让亮显式状态变暗；要让 UI 真正变暗要 `eval document.documentElement.setAttribute('data-theme','dark')`。
